# The Brij Villa — Jaisalmer

A luxury heritage villa website for **The Brij Villa**, Jaisalmer. Built as a single-page, fully responsive website with modern animations, elegant UI, smooth scrolling, and zero external framework dependencies.

🔗 Live Demo: _(https://rishid1221.github.io/Brij-villa/)_

---

## Features

- Elegant hero section with immersive visuals and smooth animations
- Fully responsive design for desktop, tablet, and mobile
- Luxury Rooms & Suites showcase
- Explore the Golden City section highlighting Jaisalmer attractions
- Interactive image gallery
- About section with premium storytelling
- Amenities & Services section
- Testimonials section
- Contact & enquiry form
- Embedded Google Map
- Sticky navigation with smooth scrolling
- SEO-friendly structure and semantic HTML
- Lightweight and fast loading
- No frameworks or build tools required

## Getting Started

No build tools or dependencies are required.

### Clone the repository

```bash
git clone https://github.com/Rishid1221/Brij-villa.git
cd Brij-villa
```

### Open locally

Simply open `index.html` in your browser, or run a local server.

Using Python:

```bash
python3 -m http.server 5500
```

or using Node:

```bash
npx serve .
```

Then open

```
http://127.0.0.1:5500
```
